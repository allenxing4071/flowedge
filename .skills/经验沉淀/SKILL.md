# FlowEdge 经验沉淀 Skill

> **核心原则：踩过的坑不踩第二次，好的实践要固化下来。**

## 触发词
产出新经验/新坑位/新最佳实践时，按经验类型路由到对应 Skill。本文件作为无明确归属经验的暂存区。

|---|---|
| 币安 WS/REST API 坑位 | `.skills/数据质量/SKILL.md` |
| Coinglass/Coinalyze API 问题 | `.skills/数据质量/SKILL.md` |
| 特征计算逻辑/算法改进 | `.skills/特征工程/SKILL.md` |
| 部署/环境/Docker 问题 | `.skills/部署运维/SKILL.md` |
| 项目结构/架构变更 | `.skills/项目入门/SKILL.md` |
| 无明确归属 | **本文件** |
