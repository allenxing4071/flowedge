## 二、做市商的核心赚钱逻辑

### 2.1 做市商 vs 订单流交易者 — 本质区别

| 维度 | 做市商（Market Maker） | 订单流交易者（Order Flow Trader） |
|---|---|---|
| **赚钱方式** | 赚取 Bid-Ask Spread（买卖价差） | 跟随大资金方向赚取价格波动 |
| **市场角色** | 流动性提供者，保持中立 | 流动性消费者，有方向性 |
| **核心能力** | 库存管理 + 对冲 + 报价调整 | 读懂盘口 + 识别大单意图 + 快速执行 |
| **盈利稳定性** | 高（与市场涨跌无关，有交易就有利润） | 低（依赖波动性，平静市场无法盈利） |
| **风险特征** | 低（双向报价 + 对冲，无方向暴露） | 高（方向性头寸，逆势即亏损） |
| **数据依赖** | 自身挂单 = 实时感知市场供需 | 依赖已成交数据，天然滞后 |
| **适用环境** | 任何市场环境（只要有交易发生） | 仅限高波动 + 高流动性环境 |

**核心洞察**：做市商赚的是"市场运转的手续费"，订单流交易者赚的是"预判方向的差价"。两者的信息来源相同（盘口/订单流），但用法完全不同。

### 2.2 做市商的信息优势

做市商因为**持续挂出买卖订单**，天然拥有以下信息优势：

1. **实时供需感知**：自己的订单就是市场的一部分，能第一时间感知哪些价位被消耗
2. **订单流第一手数据**：每一笔成交都能看到是吃了自己的买单还是卖单
3. **库存即信号**：库存偏多 = 市场在卖，库存偏空 = 市场在买
4. **报价即操控**：通过调整报价宽窄，可以主动引导或阻止交易发生

> **对 FlowEdge 的启发**：我们无法成为做市商，但可以**通过观察做市商的行为痕迹**来推断他们的意图。

### 2.3 做市商的风险管理方法

- **双向报价**：始终同时挂买单和卖单，不持有方向性头寸
- **库存管理**：当某一方向库存积累过多，立即调整报价（提高卖价或降低买价）来平衡
- **对冲策略**：用衍生品或关联品种对冲方向性风险
- **分散挂单**：将订单分散到多个价位，避免单一价位被大单打穿
- **实时调整**：毫秒级调整报价，响应市场变化

## 三、散户可利用的做市商逻辑

### 3.1 识别做市商行为痕迹

通过盘口数据可以观察到的做市商行为：

| 行为 | 盘口表现 | 含义 | FlowEdge 对应因子 |
|---|---|---|---|
| **假墙（Spoofing）** | 大额挂单出现后迅速撤销（<5秒） | 制造虚假支撑/阻力，诱导散户方向 | `depth_change.wall_events_30s` ✅ |
| **吸收（Absorption）** | 大量卖单成交但价格未下跌 | 有大资金在该价位持续接盘 | 待新增 ❌ |
| **止损猎杀** | 价格快速突破关键位后立即反转 | 做市商猎取止损单流动性后反向操作 | 待新增（需止损位估算）❌ |
| **冰山单** | 某价位反复出现小额成交，但总量巨大 | 大单分拆隐藏，避免暴露真实意图 | 可通过 aggTrade 分析 ⚠️ |
| **撤单加速** | 某价位挂单被大量撤销 | 做市商撤退，该价位即将被突破 | 可通过 depth 变化检测 ⚠️ |
| **挤压（Squeeze）** | 快速拉升/砸盘到止损密集区 | 做市商收割止损后获得流动性 | `liquidation` 因子部分覆盖 ⚠️ |

### 3.2 关键数据工具及其赚钱逻辑

#### Market Depth（市场深度 / DOM）

**核心价值**：实时展示每个价格层级的挂单数量，是观察做市商行为的第一窗口。

**赚钱逻辑**：
- 看到某价位大量买单堆积 → 判断为支撑位 → 在该位附近做多
- 看到某价位大量卖单堆积 → 判断为阻力位 → 在该位附近做空
- 大额挂单突然消失 → 支撑/阻力失效信号 → 顺突破方向跟进
- 挂单被快速"吃掉" → 方向性力量很强 → 跟随该方向

**关键指标**：
- 订单层级显示：前 5-10 档买卖挂单
- 买卖力量对比：买单总量 vs 卖单总量
- 挂单动态变化：新增/消失/被成交的速度
- 流动性分析：不同价位的挂单密度

**FlowEdge 现状**：通过 `depth@100ms` 获取 L2 数据，`DepthChangeDetector` 已实现深度不平衡和假墙检测，但缺少挂单消失速度、吸收检测。

#### Volume Profile（VP / 成交量分布）

**核心价值**：揭示价格与成交量的关系，找到市场的"公平价值"区域。

**赚钱逻辑**：
- **POC（控制点）**：成交量最高的价格 = 市场共识的"公平价格"，价格倾向于回归此处
- **HVN（高成交量节点）**：大量成交区域 = 支撑/阻力位，价格在此区域倾向于盘整
- **LVN（低成交量节点）**：低成交区域 = 价格真空带，价格快速穿越
- **Value Area（价值区域，70%-80%成交量）**：价格在此区间内来回震荡的概率高

**交易策略**：
- 价格跌到 HVN → 买入（支撑）
- 价格冲到 HVN → 卖出（阻力）
- 价格穿越 LVN → 顺势跟随（趋势确认）
- 价格回归 Value Area → 均值回归交易

**FlowEdge 现状**：未实现 ❌。可通过 `aggTrade` 累计每个价格层级的成交量来构建实时 VP。

#### Footprint Chart（足迹图）

**核心价值**：将每个价格层级的成交量按买卖方向拆分，是 VP 的精细化升级版。

**赚钱逻辑**：
- 某价位大量买单成交但价格未涨 → **吸收信号**（大资金在卖方接盘）→ 看涨
- 某价位大量卖单成交但价格未跌 → **吸收信号**（大资金在买方接盘）→ 看跌
- Delta（买单量 - 卖单量）极端偏离 → 多空失衡 → 方向性交易信号
- 结合 VP 看：HVN 处的 Delta 方向 = 大资金在该价位的真实意图

**FlowEdge 现状**：部分覆盖。`CVD`（累计成交量 Delta）已实现，但未按价格层级拆分，缺少真正的 Footprint 数据结构。

## 四、正态分布与价值区域理论

### 核心观点（南哥 + PYTA 共通）

> 市场 70% 的时间在"价值区域"内运动，只有 7% 的时间处于极端（尾部）。

- 价格符合正态分布，围绕 POC（控制点）波动
- 偏离价值区域越远，回归概率越大
- VWAP 是动态的"公平价格"，VP 是静态的"公平价格"
- 做市商利用这个规律：**在价值区域两端挂单，赚取回归利润**

### 对 FlowEdge 的应用价值

| 概念 | 实现难度 | 数据来源 | 优先级 |
|---|---|---|---|
| 实时 VWAP | 低 | `aggTrade`（价格 × 数量累加） | 🔴 高 |
| 实时 VP（按价格层级累计成交量） | 中 | `aggTrade` | 🔴 高 |
| POC 计算 | 低 | VP 最大值 | 🔴 高 |
| Value Area 计算 | 中 | VP 的 70% 覆盖范围 | 🟡 中 |
| 正态分布边界检测 | 中 | VWAP ± N × 标准差 | 🟡 中 |

| 差距 | 做市商标准 | FlowEdge 现状 | 可改进性 |

## 六、核心结论

### 6.1 做市商逻辑对 FlowEdge 的价值

1. **不要模仿做市商赚价差**：我们没有 Colocation、没有 Maker 返佣、没有 L3 数据，无法做真正的做市
2. **要学习观察做市商留下的痕迹**：假墙、吸收、止损猎杀、撤单加速 — 这些都是可检测的信号
3. **VP + VWAP 是低成本高回报的增强**：只需 `aggTrade` 数据就能实现，直接提升支撑阻力判断
4. **吸收检测是最有价值的新增因子**：大量成交但价格不动 = 大资金意图最直接的暴露

### 6.2 优先实施路线图

```
阶段 1（P0，利用现有数据）:
  ├── 新增 VWAP 计算（aggTrade 累计）
  ├── 新增 Volume Profile（按价格分桶）
  ├── 新增吸收检测（成交量 vs 价格变化的背离）
  └── 将以上作为新因子接入 scorer.py

阶段 2（P1，增强检测能力）:
  ├── 撤单速率因子（depth 快照 diff）
  ├── 止损位估算（近期高低点 + 整数关口）
  └── 优化假墙检测（结合撤单速率）

阶段 3（P2，精细化分析）:
  ├── Footprint 数据结构（按价位拆分 Delta）
  ├── 冰山单检测
  └── 综合做市商意图评分
```

## 七、经验沉淀

### 经验：做市商逻辑与订单流分析的本质差异
- 现象: 初期容易把"做市商逻辑"和"订单流分析"混为一谈
- 根因: 两者使用相同的数据源（盘口/订单流），但逻辑完全相反 — 做市商赚价差保持中立，订单流交易者赚方向性波动
- 解决: FlowEdge 定位为**订单流分析系统**，核心目标是**通过观察做市商行为来跟随大资金方向**，而非成为做市商
- 关联: 本文件第二章
- 日期: 2026-02-11

### 经验：VP/VWAP 是最低成本的系统增强
- 现象: PYTA 和南哥都将 VP + VWAP 作为核心工具，但 FlowEdge 尚未实现
- 根因: 这两个工具只需要 aggTrade 数据就能计算，不需要额外数据源
- 解决: 优先实现 VWAP 和 VP，作为新的评分因子接入 `scorer.py`
- 关联: `flowedge/signals/scorer.py`, `flowedge/features/`
- 日期: 2026-02-11

### 经验：吸收检测是识别大资金意图的最直接信号
- 现象: 南哥和 PYTA 都强调"大量成交但价格不动"是最重要的盘口信号
- 根因: 当卖单大量成交但价格不跌，说明有等量的买方在暗中接盘 — 这是大资金积累仓位的最典型行为
- 解决: 新增吸收检测因子：监控 aggTrade 成交量与价格变化的背离
- 关联: `flowedge/features/`, `flowedge/signals/scorer.py`
- 日期: 2026-02-11
