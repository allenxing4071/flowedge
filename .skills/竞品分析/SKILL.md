## 二、做市商的核心赚钱逻辑

### 2.1 做市商 vs 订单流交易者 — 本质区别

| 维度 | 做市商（Market Maker） | 订单流交易者（Order Flow Trader） |
|---|---|---|
| **赚钱方式** | 赚取 Bid-Ask Spread（买卖价差） | 跟随大资金方向赚取价格波动 |
| **市场角色** | 流动性提供者，保持中立 | 流动性消费者，有方向性 |
| **核心能力** | 库存管理 + 对冲 + 报价调整 | 读懂盘口 + 识别大单意图 + 快速执行 |
| **盈利稳定性** | 高（与市场涨跌无关，有交易就有利润） | 低（依赖波动性，平静市场无法盈利） |
| **风险特征** | 低（双向报价 + 对冲，无方向暴露） | 高（方向性头寸，逆势即亏损） |
| **数据依赖** | 自身挂单 = 实时感知市场供需 | 依赖已成交数据，天然滞后 |
| **适用环境** | 任何市场环境（只要有交易发生） | 仅限高波动 + 高流动性环境 |

**核心洞察**：做市商赚的是"市场运转的手续费"，订单流交易者赚的是"预判方向的差价"。两者的信息来源相同（盘口/订单流），但用法完全不同。

### 2.2 做市商的信息优势

做市商因为**持续挂出买卖订单**，天然拥有以下信息优势：

1. **实时供需感知**：自己的订单就是市场的一部分，能第一时间感知哪些价位被消耗
2. **订单流第一手数据**：每一笔成交都能看到是吃了自己的买单还是卖单
3. **库存即信号**：库存偏多 = 市场在卖，库存偏空 = 市场在买
4. **报价即操控**：通过调整报价宽窄，可以主动引导或阻止交易发生

> **对 FlowEdge 的启发**：我们无法成为做市商，但可以**通过观察做市商的行为痕迹**来推断他们的意图。

### 2.3 做市商的风险管理方法

- **双向报价**：始终同时挂买单和卖单，不持有方向性头寸
- **库存管理**：当某一方向库存积累过多，立即调整报价（提高卖价或降低买价）来平衡
- **对冲策略**：用衍生品或关联品种对冲方向性风险（Delta Neutral + Vega 调整）
- **分散挂单**：将订单分散到多个价位，避免单一价位被大单打穿
- **实时调整**：毫秒级调整报价，响应市场变化
- **期权锁定**：通过期权-期货对冲实现无风险挂单，期权 Gamma 压住位置成为天然日内支撑阻力

## 三、做市商行为模式详解（实战提炼）

### 3.1 大象与蚂蚁博弈模型

> 来源：南哥系列 —— "如何找到市场大型算法"

市场 85% 成交量由算法和大型机构（"大象"）主导，散户成交量仅约 5%。

**核心方法**：
1. K 线图形确认支撑阻力（宏观位置）
2. 深度数据看里面有没有大型机构介入（"找大象"）
3. 观察后续中小算法（"蚂蚁"）是跟随大象还是围攻大象
4. 谁胜出就跟谁

### 3.2 Sweep 扫单与猎止损

> 来源：南哥系列 —— "如何跟随主权基金打散户止损"

大型算法通过单一 ID 执行 Sweep：
1. **第一步**：用 limit 挂单向下清扫散户止损（不是市价单！）
2. **第二步**：用市价单守护仓位（加强型确认）
3. **第三步**：在更低位置挂单吸筹

> **关键判定**：真正的 Sweep 是挂单形式，需要看到"扫单 + 加强型守护"两步确认。2-3 分钟内单一 ID 可获利 70 万美元。

### 3.3 冰山订单与隐藏大单

> 来源：南哥系列 —— "机构如何隐藏大额订单"

- 大型机构使用**动态冰山订单**（非静态暗冰）在一定区域内分批填充仓位
- 如 1000 手分散植入，盘口上看不到红/绿泡泡
- **关键洞察**：所有人都能看到的泡泡不是优势，隐藏的巨大泡泡才是

### 3.4 双向流动性挤压

> 来源：南哥系列 —— "场内交易员提供流动性做单方法"

- 做市商在 **30 分钟整点前**进行双向流动性挤压
- 让散户在中间下注
- 整点后拉爆一个方向，换取散户的主动订单
- **做市商的意图不是看 K 线方向，而是看他们在进攻哪些入场位**

### 3.5 假突破与欺骗策略

> 来源：南哥系列 —— "一个视频让你不再被假突破欺骗"

- 假突破 = 做市商清扫止损后反向操作
- 识别方法：突破时看成交量（Delta）是否配合
  - 突破 + 放量 = 真突破
  - 突破 + 缩量 = 假突破（做市商猎止损）
- VP 边缘的 7% 时间和成交量特征极为关键：碰到边缘不放量就回归，放量就突破

### 3.6 可检测的做市商行为痕迹

| 行为 | 盘口表现 | 含义 | FlowEdge 对应因子 |
|---|---|---|---|
| **假墙（Spoofing）** | 大额挂单出现后迅速撤销（<5秒） | 制造虚假支撑/阻力，诱导散户方向 | `depth_change.wall_events_30s` ✅ |
| **吸收（Absorption）** | 大量成交但价格未变动 | 有大资金在该价位持续接盘 | `absorption` ✅ |
| **止损猎杀** | 价格快速突破关键位后立即反转 | 做市商猎取止损单流动性后反向操作 | 待增强（需止损位估算）⚠️ |
| **冰山单** | 某价位反复出现小额成交，但总量巨大 | 大单分拆隐藏，避免暴露真实意图 | 可通过 aggTrade 分析 ⚠️ |
| **撤单加速** | 某价位挂单被大量撤销 | 做市商撤退，该价位即将被突破 | 可通过 depth 变化检测 ⚠️ |
| **挤压（Squeeze）** | 快速拉升/砸盘到止损密集区 | 做市商收割止损后获得流动性 | `liquidation` 因子部分覆盖 ⚠️ |
| **Sweep 扫单** | limit 挂单扫过关键价位 + 市价单守护 | 大型算法猎止损后建仓 | 待新增 ❌ |

## 四、关键数据工具及其赚钱逻辑

### 4.1 Delta 值 — 最核心的简化指标

> 来源：南哥系列 —— "第1集优化交易策略"

Delta = 每根 K 线内买入量 - 卖出量的净值。

- **量价同步** = Delta 方向与价格方向一致 → 趋势确认
- **量价背离** = 价格新高但 Delta 未新高 → 有大量被动订单在吸收 → 反转信号
- Delta 背离是真金白银的体现，远优于 MACD/KDJ/RSI 等价格衍生指标

**FlowEdge 现状**：CVD 已实现（权重 0.12），但缺少量价背离的显式检测。

### 4.2 Volume Profile（VP / 成交量分布）

> 来源：南哥系列 —— "第2集抄顶摸底" + "量价交易分析"

**核心价值**：揭示价格与成交量的关系，找到市场的"公平价值"区域。

- **POC（控制点）**：成交量最高的价格 = 市场共识的"公平价格"，价格倾向于回归此处
- **HVN（高成交量节点）**：大量成交区域 = 支撑/阻力位，价格在此区域倾向于盘整
- **LVN（低成交量节点）**：低成交区域 = 价格真空带，价格快速穿越
- **Value Area（价值区域，70%-80%成交量）**：价格在此区间内来回震荡的概率高
- **正态分布边缘**：碰到边缘不放量就回归，放量就突破寻找新价值区

> **南哥原话**："策略只占 25%，地图（VP 数据）占 75%。"

**FlowEdge 现状**：VP 已实现（权重 0.07），使用固定 0.01% 分桶、1 小时窗口。缺少多时间窗口 VP 和 POC 迁移追踪。

### 4.3 VWAP（成交量加权平均价）

**核心价值**：动态的"公平价格"，偏离度 = 交易信号。

- 超过 **72%** 的机构交易者使用 VWAP 算法执行低紧迫性订单（BestEx Research, 2025）
- VWAP 是机构行为的"指纹"，检测价格与 VWAP 的偏离可识别机构大单执行

**FlowEdge 现状**：VWAP 已实现（权重 0.08），但缺少 VWAP 斜率和与订单流的联动分析。

### 4.4 Market Depth（市场深度 / DOM）

> 来源：南哥系列 —— "职业交易员操作设置"

**核心价值**：实时展示每个价格层级的挂单数量，是观察做市商行为的第一窗口。

- DOM 是毫秒级无滑点的入场工具，但缺陷是不知道在大地图的哪个位置
- **需要配合 VP 确定宏观位置后，再用 DOM 在微观上精确入场**
- Tape（磁带/时间与销售）用于识别单一 ID 的大额成交

**FlowEdge 现状**：通过 `depth@100ms` 获取 L2 数据，`DepthChangeDetector` 已实现深度不平衡和假墙检测。Book Imbalance 仅使用 L1（权重 0.08），缺少加权深度分析。

### 4.5 Footprint Chart（足迹图）

**核心价值**：将每个价格层级的成交量按买卖方向拆分，是 VP 的精细化升级版。

- 某价位大量买单成交但价格未涨 → **吸收信号** → 看涨
- Delta（买单量 - 卖单量）极端偏离 → 多空失衡 → 方向性交易信号
- 结合 VP 看：HVN 处的 Delta 方向 = 大资金在该价位的真实意图

**FlowEdge 现状**：CVD 已实现但未按价格层级拆分，Absorption 检测已实现（权重 0.10），缺少真正的 Footprint 数据结构。

## 五、时间节点与交易节奏

### 5.1 30 分钟整点变盘规律

> 来源：南哥系列 —— "场内交易员" + "第2集抄顶摸底"

- 程序化算法倾向于在 **30 分钟整点**发动变盘
- 做市商在整点前进行双向挤压积累筹码，整点后选择方向发力
- 交易计划应围绕这些时间节点制定

### 5.2 每天的交易计划流程（南哥方法论）

```
1. 看 30 分钟 VP → 确定自己在成交量地图的哪个位置
2. 看 VWAP 拐向 → 确认动态趋势
3. 检查是否有重要数据发布
4. 确认 ETF 时间
5. 在盘口上选择对应策略
```

> **核心原则**：不是看到信号就做，而是先确定"在哪"再选择"用什么工具"。

### 5.3 期权 Gamma 压住位置

- 每天 23:35 公布的期权 Gamma 压住位置是天然的日内支撑阻力
- 价格在期权压住位置上方震荡后站上去会急速暴涨，跌下来则急速暴跌
- 做市商的大额挂单位置是理想的止盈目标位

## 六、风控与量化的核心认知

### 6.1 风控是交易员最重要的事

> 来源：南哥系列 —— "交易员最重要的就是风险管控"

- **重仓和复利都是伪概念** — 复利等于复亏
- 每个人有固定的回撤承受能力（不是百分比而是绝对数字），突破阈值就会执行崩溃
- **盈利出金才是王道**，保证金里的钱不是你的钱
- 账户翻倍后手数不能同比翻倍

### 6.2 量化与程序化交易的局限性

> 来源：南哥系列 —— "什么时候波段/什么时候剥头皮" + "做交易真的是心态和悟道吗"

- **人的核心优势**：对可视化数据的理解力 > 算法。算法对数字敏感但对"变化"不敏感
- **交易系统必须经受千笔统计验证**：1000 笔以上量化统计才能判断是否有效
- **"心态论"的本质**：所谓"心态不好"往往是策略胜率低的遮羞布。真正的解决方案不是练心态，而是获得深度数据、提高胜率

### 6.3 有用的数据 vs 无用的指标

> 来源：南哥系列 —— "有用的交易数据"

| 有用（真金白银） | 无用（价格衍生） |
|---|---|
| Delta（多空净量） | MACD |
| VP（成交量分布） | KDJ |
| DOM（盘口深度） | RSI |
| OFI（订单流不平衡） | 布林带 |
| 大单检测 | 超买超卖 |

> **核心观点**：价格指标是"画画"，成交量数据是"真钱"。所谓超买超卖没有意义——强势买入就是强势买入，不存在"超买"。

| 订单流信号在高波动期更有效 | **强** | 高波动期 0.60% vs 低波动期 -0.16% |
| 微观结构分析适用于加密市场 | **强** | Easley 团队 2024 直接验证 |
| 特征工程比模型复杂度更重要 | **强** | 简单模型 + 好特征 ≥ 深度学习 |
| VPIN 有效但需参数校准 | **中等** | 优化后误报率 2-7%，但对分类算法敏感 |

### 8.1 已有能力（14 因子全景）

| 3 | Book Imbalance | 0.08 | 判断即时供需 | 做市商困境论文验证 |
| 4 | Large Trade | 0.10 | 识别机构行为（"找大象"） | 平方根定律 |
| 5 | Depth Change | 0.06 | 假墙检测 + 深度不平衡 | 31% 幌骗数据 |

| 7 | Volume Profile | 0.07 | 静态公平价格 + 支撑阻力 | 南哥："地图占 75%" |

**已有的四层门卫系统**：
1. MarketRegime — 市场环境分类（trending/ranging/breakout/extreme）
2. LocationFilter — 关键价位过滤（VWAP/POC/VA边界/HVN）
3. BehaviorConfirm — 做市商行为确认（吸收/大单/假墙）
4. DirectionConfirm — 方向确认（score + confidence）

### 8.2 关键差距（按重要性排序）

#### 差距 1：OFI 时间窗口单一（高优先级 / 投入低）
- **现状**：OFI 仅使用 30 秒 z-score
- **缺失**：多时间窗口 OFI（1m/5m/15m）对比、OFI 趋势（变化率）、OFI 与价格的背离检测
- **学术依据**：广义平稳化 OFI 可将 R² 从 35% 提升至 85%+
- **改进方案**：在 `OFICalculator` 中增加多窗口计算，在 `scorer._score_ofi()` 中综合评分

#### 差距 2：订单簿深度分析不足（高优先级 / 投入中）
- **现状**：Book Imbalance 仅使用 L1（最优买卖价）
- **缺失**：L2 加权订单簿不平衡（距离价格越近权重越大）、订单簿流动性分布、挂单消失速度
- **学术依据**：做市商困境论文证明 Book Imbalance 极端偏向时反转概率更高
- **改进方案**：在 `DepthStream` 中增加加权深度计算 `Σ(qty × 1/distance)`

#### 差距 3：量价背离的显式检测（高优先级 / 投入低）
- **现状**：CVD 已实现但缺少与价格趋势的背离检测
- **缺失**：价格新高但 CVD 未新高 = 反转信号（南哥核心方法）
- **改进方案**：在 `scorer._score_cvd()` 中增加背离检测逻辑

#### 差距 4：VP 多时间窗口与 POC 迁移（中优先级 / 投入中）
- **现状**：VP 使用固定 0.01% 分桶、1 小时窗口
- **缺失**：多时间窗口 VP（5m/15m/1h/4h）、POC 迁移追踪、动态分桶
- **改进方案**：在 VP 计算器中增加多窗口支持

#### 差距 5：吸收检测与订单簿联动（中优先级 / 投入中）
- **现状**：使用量价比判断吸收
- **缺失**：吸收时订单簿的同步变化分析、吸收强度的时间衰减、连续吸收行为聚类
- **改进方案**：在 `AbsorptionDetector` 中增加订单簿联动和时间衰减

#### 差距 6：市场活跃度自适应（中优先级 / 投入低）
- **现状**：四层门卫中 MarketRegime 已分类但未动态调整因子权重
- **缺失**：高波动期放大信号、低波动期降权/暂停
- **学术依据**：订单流信号在高波动期有效（0.60%），低波动期失效（-0.16%）
- **改进方案**：根据 MarketRegime 动态调整 scorer 权重

#### 差距 7：30 分钟节点过滤（低优先级 / 投入低）
- **现状**：无时间节点过滤
- **缺失**：30 分钟整点前后的信号权重调整
- **改进方案**：在门卫中增加时间节点检查

#### 差距 8：Footprint 数据结构（低优先级 / 投入高）
- **现状**：CVD 未按价格层级拆分
- **缺失**：每个价格层级的买卖成交量对比
- **改进方案**：在 aggTrade 处理中按价格分桶统计

### 8.3 基础设施差距

| 差距 | 做市商标准 | FlowEdge 现状 | 可改进性 |
|---|---|---|---|
| 延迟 | 微秒级 | 秒级（WebSocket + Python） | 有限（Python 天花板） |
| 数据深度 | L3（逐笔委托） | L2（前 10 档 depth@100ms） | 无法改进（币安不提供 L3） |
| 交易费率 | Maker 返佣（-0.01%） | Taker 付费（~0.04%） | 可优化为 Maker 策略 |
| 直连交易所 | Colocation | 公网 WebSocket | 无法改进 |
| 单一 ID 识别 | Tape 可看到 | aggTrade 无法区分 | 无法改进（交易所限制） |

## 十、核心结论

### 10.1 做市商逻辑对 FlowEdge 的价值

1. **不要模仿做市商赚价差**：我们没有 Colocation、没有 Maker 返佣、没有 L3 数据，无法做真正的做市
2. **要学习观察做市商留下的痕迹**：假墙、吸收、止损猎杀、撤单加速 — 这些都是可检测的信号
3. **VP + VWAP + OFI 是低成本高回报的增强**：只需现有数据就能优化，直接提升信号质量
4. **吸收检测是最有价值的因子**：大量成交但价格不动 = 大资金意图最直接的暴露
5. **市场状态自适应是关键**：高波动期放大、低波动期降权，学术数据明确支持

### 10.2 FlowEdge 的定位

> FlowEdge 是**订单流分析系统**，核心目标是**通过观察做市商行为来跟随大资金方向**，而非成为做市商。
>
> 学术研究证实：微观结构分析在加密市场有效（Easley 2024），特征工程比模型复杂度更重要（LSE 2024），OFI 是短期价格变动的最佳解释变量（R²=85%+）。
>
> FlowEdge 的 14 因子 + 四层门卫架构在方法论上是正确的，当前的核心差距在于**因子精度**（OFI 多窗口、加权深度、量价背离）和**自适应能力**（市场状态动态调权），而非架构层面的缺失。

## 十一、补充结论（2026-02 二次复核）

### 11.1 核心方法论未变，新增集中在执行层

复核 `参考/` 全量文稿后，结论是：核心仍然是 **做市商行为痕迹识别 + 订单流量价框架 + 风控优先**，没有出现新的替代性主方法论。  
新增内容主要集中在三个执行层主题：

1. **交易环境真伪识别**（清算模式 vs 报价模式、资金隔离、监管对象）
2. **程序化执行边界**（结果特征可编码，过程特征需人工监督）
3. **统计风控细化**（连亏分布、回撤阈值、行为失控触发）

### 11.2 交易环境识别（前置风控，不是后置优化）

| 维度 | 竞品强调点 | 对 FlowEdge 的启发 |
|---|---|---|
| 监管对象 | 监管核心是平台，不是用户本身 | 增加执行层健康检查（执行通道质量、成交可验证性） |
| 资金路径 | 资金隔离与真实清算优先 | 回测与仿真中引入真实成本假设（滑点/点差/成交延迟） |
| 执行模式 | 清算模式优于仅报价模式 | 信号评估增加 `execution_quality` 维度，避免只看方向因子 |
| 订单可验证 | 深度与成交回放要可交叉验证 | 在风控侧记录“预期成交 vs 实际成交”偏差用于反馈调权 |

### 11.3 程序化执行边界（竞品视角）

- 程序化擅长“结果特征”编码：阈值、窗口、触发条件、风控硬规则
- 人工更擅长“过程特征”判断：盘口节奏变化、撤单速度突变、短时行为上下文
- 实战建议是 **Human-in-the-loop**：自动筛信号 + 人工确认执行，优于全自动裸跑

### 11.4 统计风控补充（连亏与回撤）

- 竞品反复强调：仅追求高盈亏比会降低胜率，放大连亏序列的心理与执行风险
- 回撤阈值（如 15%）会触发行为失真：逆势加仓、改止损、过度交易等
- 对 FlowEdge 的启发：除单笔风控外，应增加 **连亏熔断、回撤降权、交易频率节流**

### 11.5 期权-期货对冲与目标位启发

- 做市商可能通过期权/期货组合对冲库存风险，降低方向性暴露
- 长时间驻留的大挂单更适合作为“潜在目标位/分批止盈位”参考，而非直接反转信号
- 对 FlowEdge 的启发：将“大挂单持续时间 + 距离 + 成交响应”作为位置管理辅助特征

## 十二、经验沉淀

### 经验：做市商逻辑与订单流分析的本质差异
- 现象: 初期容易把"做市商逻辑"和"订单流分析"混为一谈
- 根因: 两者使用相同的数据源（盘口/订单流），但逻辑完全相反 — 做市商赚价差保持中立，订单流交易者赚方向性波动
- 解决: FlowEdge 定位为**订单流分析系统**，核心目标是**通过观察做市商行为来跟随大资金方向**，而非成为做市商
- 关联: 本文件第二章
- 日期: 2026-02-11

### 经验：VP/VWAP 是最低成本的系统增强
- 现象: PYTA 和南哥都将 VP + VWAP 作为核心工具，FlowEdge 已实现但精度不足
- 根因: VP 缺少多时间窗口，VWAP 缺少斜率和订单流联动
- 解决: 优先增强 VP 多窗口 + VWAP 斜率，作为门卫 LocationFilter 的增强输入
- 关联: `flowedge/signals/scorer.py`, `flowedge/features/`
- 日期: 2026-02-11

### 经验：吸收检测是识别大资金意图的最直接信号
- 现象: 南哥和 PYTA 都强调"大量成交但价格不动"是最重要的盘口信号
- 根因: 当卖单大量成交但价格不跌，说明有等量的买方在暗中接盘 — 这是大资金积累仓位的最典型行为
- 解决: 增强吸收检测：加入订单簿联动 + 时间衰减 + 连续吸收聚类
- 关联: `flowedge/features/absorption.py`, `flowedge/signals/scorer.py`
- 日期: 2026-02-11

### 经验：OFI 优化后预测力可提升 2.5 倍
- 现象: 学术研究显示广义平稳化 OFI 的 R² 从 35% 提升至 85%+
- 根因: 原始 OFI 受非平稳性影响，对数化和平稳化处理可大幅提升
- 解决: 在 OFI 计算中加入对数化处理 + 多时间窗口 + 趋势分析
- 关联: arXiv:2112.02947, `flowedge/features/ofi.py`
- 日期: 2026-02-11

### 经验：订单流信号在低波动期失效
- 现象: 学术回测显示高波动期季度收益 0.60%，低波动期 -0.16%
- 根因: 做市商在波动中更活跃，低波动期信号噪声比下降
- 解决: FlowEdge 需内置市场活跃度检测器，低波动期降低信号权重或暂停信号生成
- 关联: arXiv:2512.12924, `flowedge/signals/engine.py`
- 日期: 2026-02-11

### 经验：加密市场 31% 大额订单可能是幌骗
- 现象: 2025 年学术研究发现加密交易所近三分之一大额订单可能构成幌骗
- 根因: 加密市场监管相对宽松，操纵成本低
- 解决: 假墙检测（Feature #5）是 FlowEdge 的差异化优势，应持续增强
- 关联: arXiv:2504.15908, `flowedge/features/depth_change.py`
- 日期: 2026-02-11

### 经验：交易环境质量是信号能否兑现的前置条件
- 现象: 同一套信号逻辑在不同执行环境中结果差异巨大
- 根因: 点差、滑点、延迟、成交可验证性会系统性吞噬边际优势
- 解决: 在策略评估中新增执行质量维度（成本、延迟、成交偏差），避免只按方向准确率评估
- 关联: 本文件第十一章，`flowedge/signals/engine.py`
- 日期: 2026-02-13

### 经验：程序化应负责筛选，人工负责过程监督
- 现象: 全自动策略在微观节奏突变时容易执行劣化
- 根因: 盘口“过程特征”难以被固定规则完整编码
- 解决: 采用 Human-in-the-loop：程序化筛选 + 人工确认 + 风控兜底
- 关联: 本文件第十一章，`flowedge/signals/entry_gate.py`
- 日期: 2026-02-13
